# Pràctica Git

**Autor:** Carlos Martí Campos
**Data:** 26/11/2025

Aquesta pràctica assolirà els següents objectius:

1. Aprendre les ordres principals de Git.
2. Practicar l'ús de branques i fusions (merge).
3. Mantenir una estructura clara amb fitxers `.txt`.
4. Publicar els canvis al vostre repositori personal.
5. Representar visualment l'històric de commits i branques amb un gràfic.
