# Instruccions principals de Git

## git init
Inicialitza un repositori nou.

## git status
Mostra els canvis pendents.

## git add
Afegeix fitxers a l'índex.
Exemple: `git add .`

## git commit
Guarda un punt de control a l'historial.
Exemple: `git commit -m "Missatge"`

## git push
Envia els canvis al repositori de GitHub.
